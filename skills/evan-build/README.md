# `evan-build` 技能

[English](README_EN.md)

`evan-build` 用于严格按照已定稿冻结（`状态: FROZEN`）的仓库外 `PLAN.md` 连续实施开发阶段，完成 worktree 自动落地、强相关 Diff 复核、测试回归、受控 Open Code Review、按项目规范提交、5 行交接快照回写、授权后的 T3 优先跨线程接力、最终 PR 收口及 PR 评审反馈修复。

## 适合用它做什么

- 默认按顺序一次性连续跑完全部阶段，每阶段独立验收提交，仅在用户要求“每阶段跑完汇报”或指定单阶段时中途停下。
- 强制“改码必重测”：每次修复（含审查后修改）都基于最新代码重跑验收与回归命令并核对实际输出。
- 提交前强制执行 `git diff --stat` 对照 `PLAN.md` 强相关文件清单，并完成受控的 Open Code Review（默认 1 次，高风险改动最多 1 次复审）。
- 只提交阶段验收所需的代码、测试与配套文件，提交后将真实短哈希、五态进度与 5 行交接快照写回仓库外 `PLAN.md`，绝不把计划文件带进 Git 提交。
- 计划里 `接力授权: 已确认` 时，优先使用 T3 Code 新建干净顶层线程连续接力（未授权或非 T3 环境输出可复制极简接力提示词），末阶段先 `git fetch` 再执行 `git merge-tree` 冲突预检、整分支审查、提议 `ci-test`，并输出可直接提 PR 的交付摘要。
- 提交信息遵循项目规范（计划里的 `提交规范` 与 `关联工单`，查不到约定才默认简体中文）。
- PR 提交后收到评审意见或 CI 失败时，作为追加的“评审修复”阶段处理，只本地提交，是否推送由你决定。

## 工作方式

1. **定位计划、落地 worktree 与双重核对**：按“你给的路径 → worktree 内指针文件 → 默认路径”找到 `PLAN.md`，确认为 `状态: FROZEN`；阶段 1 按计划自动在 `~/.t3/worktrees/<owner__repo>/<slug>` 创建新分支和 worktree 并写入指针文件；后续阶段先 `git fetch`，再用“5 行交接快照 + Git 真实 `HEAD`”双重核对后起步，参考分支有新提交影响计划时转 `REVISING`。
2. **单线程实施、强相关 Diff 与硬验证**：按计划最小改动实施，执行 `git diff --stat` 核对无无关修改后运行验收与跨模块回归，改码必重测。
3. **审查、纯业务提交与连续接力**：执行 1 次 Open Code Review 并集中修复阻塞，按项目规范做纯业务 `git commit`，回写真实短哈希与 5 行交接快照到仓库外 `PLAN.md`，获得接力授权后优先在 T3 自动开新线程连续推进；末阶段输出 PR 摘要并等用户确认，再按计划的同步方式与合并方式收口，推送远端与提 PR 始终由用户决定。

## 典型请求

- “按 `~/.t3/plans/<owner__repo>/<slug>/PLAN.md` 开始实施。”
- “按计划执行，每阶段跑完结束跟我汇报。”
- “核对 `PLAN.md` 交接快照，继续完成剩余阶段并准备 PR 摘要。”

## 你需要提供

- 状态为 `FROZEN` 的 `PLAN.md` 路径。
- 如需每阶段停下汇报或只跑特定阶段，可显式说明（未说明则默认连续跑完）。
- 最终本地合回删临时分支，以及推送远端、提 PR 需等你确认后再执行。

## 产出

- 对应阶段的纯业务代码与测试提交（遵循项目提交规范）。
- 更新后的仓库外 `PLAN.md`（包含五态进度、真实短哈希、关键裁决与 5 行交接快照）。
- T3 接力场景下的新顶层线程链接（非 T3 环境为极简接力提示词），以及末阶段可直接粘贴提 PR 的交付摘要。

## 边界

- 不接受未定稿（非 `FROZEN`）的计划；缺计划时先定位或请你指明；已有计划的契约或验收条件需要变更时，才转 `REVISING` 并交回 `evan-plan`。
- 不自动执行未经你逐次单独授权的 `git push`、创建或更新 PR、合并 PR、强推或线上部署；`git merge-tree` 预检出冲突时只汇报，不自动解决。
- 不经你授权的情况下不自动开新线程接力。
- 代码审查默认调用 `open-code-review`（本机 `ocr` CLI）或回退 `open-code-review-delegate`；线程接力依赖 T3 Code 的 `t3_worktree_status` / `t3_thread_launch` 工具，在普通终端或无对应工具的 Agent 中可按单线程模式手动开新会话继续。
